The lever already exists - "sizing by input" in the settings-panel.css contract: shrink under `@media (pointer: fine)` only, every family together, touch keeps today's sizes. Figma gets criticized for going too small; this is a personal site, so going small is allowed if it buys realism. Side by side at the same scale (Derek's screenshot, 2026-09-26) it isn't one direction - "some things are smaller, some bigger, we'll massage it into place": Claude's TEXT is bigger (a ~14-17px sans) but its MARKS are thinner and grayer (hairline icons, gray bullets, gray "More"); ours is smaller text (12px mono) with heavier marks (full-ink radio dots and knobs, thick glyph strokes, a ~5px ringed edge). The "bulbous" read is weight and ink, not size. Candidate moves, all paint: the pill mark as a slot (radio / quiet radio / bracket / sunken / none - Interface = quiet radio first), knobs in secondary ink, a thinner edge, lighter glyph strokes.
